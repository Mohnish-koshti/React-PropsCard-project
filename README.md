# 💼 Job Cards UI (React.js Props)

A modern and responsive **Job Cards UI** built while learning **React.js Props**. This project demonstrates how to create **reusable components** and pass data dynamically using **props**.

Instead of writing multiple job cards manually, all card information is stored in an array and rendered dynamically using reusable React components.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/job-cards-react.git
```

Go to the project folder

```bash
cd job-cards-react
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```
